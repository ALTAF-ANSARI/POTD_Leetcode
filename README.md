# 🚀 365 Days of LeetCode — The Consistency Challenge

> **One problem a day. One step closer to mastery.**
>
> Great developers are not built in a day. They are built through the discipline of showing up every single day.

Welcome to my daily coding journey! This repository documents my commitment to solving **LeetCode Problem of the Day (POTD)** challenges, strengthening Data Structures and Algorithms, and becoming a better problem solver.

## 🎯 The Mission

- Solve the LeetCode Problem of the Day consistently.
- Understand the problem before jumping into code.
- Explore clear and efficient approaches.
- Write clean, readable, and optimized C++ solutions.
- Analyze time and space complexity.
- Learn from mistakes and improve with every submission.
- Build a habit of consistency that lasts beyond a 365-day challenge.

## 🧠 The Daily Workflow

1. **Understand** — Read the problem, constraints, and examples carefully.
2. **Think** — Identify the pattern and develop an approach.
3. **Solve** — Implement the solution and test edge cases.
4. **Optimize** — Evaluate time and space complexity; improve where possible.
5. **Reflect** — Record the key concept and what the problem taught me.
